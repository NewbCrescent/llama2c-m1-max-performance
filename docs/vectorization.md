# Clang vectorization inspection

Compiler: `Homebrew clang version 23.1.0`

Generated by `python3 benchmarks/inspect_vectorization.py`. The report compares the same scalar matmul source under standards-conforming `-O3` and `-O3 -ffast-math`.

## What changed

Both builds recognize vectorizable work. The strict build preserves the ordered floating-point reduction: it performs vector multiplies, extracts lanes, and accumulates them serially. With `-ffast-math`, Clang may reassociate the reduction, so it emits independent vector FMA accumulators and performs the horizontal reduction once after the loop. That instruction-level difference, not merely the presence of SIMD registers, explains the large throughput gap.
